# Autobile 0.11.0

This release makes the agent, not the recording, responsible for getting a task done.
A demonstration now tells Autobile where to go; when the screen disagrees with it, the
agent works from what it sees until the goal is visibly reached.

## Operate by asking

- Type what you want on the home screen. A request that matches a saved automation runs
  it; any other request runs as a confirmed one-off task that opens the app you named and
  works toward the goal from the current screen.
- Give an automation an instruction for a single run — "on hard this time" — from its
  page, or by naming it in a typed request. Its normal behaviour is unchanged.

## Corrections that stick

- A correction the recorded steps cannot express is no longer rejected. It is kept as a
  standing instruction, shown on the automation's page, and followed on every run, with
  the demonstration used as the reference route.
- Corrections that do map to steps are still applied to the steps.

## Getting past what the demonstration did not show

- Reward pop-ups, tutorials, rating prompts, dialogs and moved controls are handled by the
  agent from the current screen, after which the recorded route resumes. If the route
  stops fitting a second time, the agent finishes the goal.
- A rejected or failed action, a runtime timeout, or a malformed reply is fed back to the
  agent instead of ending the run.
- The agent can choose several actions in one turn when they do not change the layout
  between them, such as selecting a puzzle cell and then a digit.
- Close buttons near the top of a pop-up and bottom tab bars are now reachable; the status
  and navigation bars are still not.

## Cloud reliability

- OpenAI reasoning models receive `reasoning_effort` instead of a temperature, with room
  reserved for reasoning. Their structured answers previously came back empty.
- Gemini 2.5 Flash and Pro receive an explicit thinking budget on top of the answer.

## Safety

- Every agent action passes the same app policy and risk engine as taught steps.
  Purchases, payments, transfers and subscriptions — recognised from the control's words
  or declared by the agent — always require your approval.
- The agent cannot use Home, Recents or the system bars, cannot act on Autobile, and is
  returned to the task's app if another one takes over.
- Completion still requires two consecutive fresh observations.

## Privacy

- Agent prompts now carry the automation's instructions, the demonstrated route, and
  values the run already knows, each capped in length. Screenshots are still sent only
  with their own consent.

## Upgrade

Install over an existing version. Saved automations keep replaying their recorded steps
and gain agent recovery automatically. A correction the recorded steps cannot express
switches that automation to agent-first execution.
