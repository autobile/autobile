# Autobile 0.9.1

This patch removes an unreachable review state from autonomy enforcement.

## Fixed

- `Watch only` now reports that it does not control the screen and points to **How much
  freedom it has → Ask first** instead of referring to a review screen that does not
  exist.
- An automation whose confidence degrades now runs in attended `Ask first` mode. It no
  longer falls into a permanent state where it cannot run and therefore cannot regain
  confidence.
- `Ask first` now requests confirmation for low-risk actions as its label promises.
- The detail screen explains both an explicitly selected `Watch only` setting and a
  temporary confidence-based autonomy cap.

## Safety

- An explicitly selected `Watch only` setting still prevents every screen mutation.
- Degraded runs require user confirmation; this patch does not grant unattended
  autonomy or bypass app and action risk policies.
