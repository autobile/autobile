# Autobile 0.7.3

This patch makes finish-before-exit game corrections executable and verifiable.

## Fixed

- Plain-language requests to finish a game before exiting retain the recorded exit
  action and place a bounded screenshot-grounded gameplay loop before it.
- Victory, clear, results, or another unambiguous completion state must be verified
  before the exit action can run; ordinary visual progress is not sufficient.
- Each progressing game action is grounded again from fresh pixels without treating a
  coordinate as permanently invalid after the game board changes.
- Explicit Home actions validate the intended launcher transition without inheriting
  the preceding game's foreground-package requirement.

## Upgrade

Install this APK over an existing Autobile installation. Existing automations and
ChatGPT Subscription sessions are retained. Re-submit a previously rejected
finish-before-exit correction from the automation detail screen.
