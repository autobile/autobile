# Autobile 0.9.2

This patch removes avoidable per-turn latency from screenshot-driven games.

## Performance

- Visual tasks no longer wait up to 5–8 seconds for an accessibility tree to stop
  changing after every gesture. Animated games and timers often never satisfy that
  condition.
- After an action, Autobile performs one short package-identity observation and then
  captures fresh pixels for the next model decision.
- Retained action history is bounded to the same 12 recent actions already sent to the
  model.

## Safety

- Every model decision still uses a fresh screenshot.
- App-package containment, Android system-edge exclusion, gesture safety checks, and
  two fresh completion confirmations remain unchanged.
