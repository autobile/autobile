# Autobile 0.7.2

This patch fixes edit persistence and false-success recovery on full-screen games.

## Fixed

- Plain-language requests such as keeping a game open now remove recorded exit/Home
  steps and add an observable foreground-app post-condition.
- Unsupported behavior edits are rejected instead of being reported as applied.
- The currently active automation version appears in version history immediately.
- Direct edits and accepted recovery proposals refresh the detail screen atomically.
- Visual grounding cannot select Android status or navigation controls as app targets.
- Visual grounding is explicitly forbidden from selecting Home, Back, Recents, or an
  app-exit control unless that is the requested action.
- A cloud model cannot confirm game progress after the automation leaves the game; the
  runtime restores the intended app before another recovery attempt.

## Upgrade

Install this APK over an existing Autobile installation. Existing automations and
ChatGPT Subscription sessions are retained.
