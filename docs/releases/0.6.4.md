# Autobile 0.6.4

This patch release restores application startup on supported Android devices and adds
device startup to the required release gate.

## Startup repair

- Fix a temporal-template regular expression that the desktop JVM accepted but Android
  11's ICU engine rejected during process initialization.
- Verify that the minified release APK installs, launches its exported activity, remains
  alive, and reaches the resumed state on API 30.

## Faster verification

- Run only the debug unit-test variant instead of compiling duplicate release variants.
- Reuse the minified APK assembled by the build job for device startup verification.
- Enable KVM acceleration for the emulator.
- Build only the signed artifact in the tag workflow after the protected merge commit
  has passed the complete verification gate.

## Verification

The protected branch gate runs Android lint, debug unit tests, debug assembly, minified
release assembly, and an API 30 minified-APK startup smoke test. The release workflow
then rebuilds and verifies the signed APK from the tested merge commit.
