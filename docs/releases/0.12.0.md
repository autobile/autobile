# Autobile 0.12.0

This release makes the steps the source of truth again. You can edit them directly, and
what the agent works out on the screen is written back as steps, so the next run replays
it without a model.

## Edit steps directly

- The step list on the review screen after a demonstration, and on every automation's
  page, can be edited without writing a sentence: move a step, change what it types or how
  long it waits, make it optional, remove it, or add a tap, text entry, wait, back, app
  launch or goal step after any other.
- Every change applies at once, involves no model, and is saved as a new version you can
  roll back from the version history.

## The agent writes down what it learned

- When the agent reaches the goal using controls it can name, the route it took becomes
  steps with the ids and labels needed to find them again.
- A pop-up or tutorial it cleared on the way to a recorded step is kept in front of that
  step as an optional check. When it does not appear, the check costs one lookup and no
  model call.
- An automation the agent drove from start to finish is rewritten to the proven route and
  replays it from then on, falling back to the agent only where the screen differs.
- Automations you let act on their own adopt the new steps immediately. Others show them
  as a repair to review, as does any route touching a purchase, payment, transfer or
  subscription. Instructions for a single run and taps on a canvas are never learned.

## Faster turns

- The agent decides from the screen's named controls and sends a screenshot only when it
  needs one: a canvas, a screen that did not react, a refused proposal, or a completion to
  check.
- A completion is confirmed on a fresh, unchanged screen without asking the model again.
- ChatGPT subscription models are asked for low reasoning effort when they advertise it.

## Fixed

- A version saved during a run, such as a learned route, is no longer overwritten when the
  run updates the automation's confidence.

## Upgrade

Install over an existing version. Automations and their history are kept. An automation
that became agent-first in 0.11.0 returns to replaying steps once a successful run learns
its route: straight away if it may run low-risk steps on its own, otherwise when you apply
the proposed repair.
