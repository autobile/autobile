# Autobile 0.6.1

This patch release repairs ChatGPT subscription fallback after an on-device runtime is
restricted in the background.

## Runtime routing

- Replace retired subscription preset models with models currently advertised by the
  Codex subscription catalog.
- Discover the signed-in account's supported API models and fall back to the first
  server-prioritized model when a preset is no longer available.
- Migrate the exact model defaults persisted by v0.6.0 while preserving explicit custom
  model overrides.
- Distinguish invalid requests and unavailable models from image-modality failures in
  execution history.

## Verification

The release workflow runs Android lint, all unit tests, debug assembly, minified release
assembly, APK signature verification, and SHA-256 generation from the protected `main`
commit before publishing artifacts.
