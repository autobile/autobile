# Autobile 0.6.3

This patch release makes the dynamic date and time fix update-compatible with existing
automations.

## Existing automations

- Recognize a date or timestamp still stored as literal text by an earlier app version.
- Render that span from the current run time while preserving its demonstrated format
  and all surrounding note content.
- Apply the same conservative date-distance rule as new-skill compilation, avoiding
  broad replacement of unrelated numbers or distant fixed dates.

No recreation, re-teaching, or natural-language correction is required.

## Verification

The release workflow runs Android lint, all unit tests, debug assembly, minified release
assembly, APK signature verification, and SHA-256 generation from the protected `main`
commit before publishing artifacts.
