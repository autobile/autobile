# Autobile 0.5.0

This release repairs the execution boundary where an Android app exposes a control but
does not honor the accessibility action sent to it.

## What changed

- Text entry now falls back from `ACTION_SET_TEXT` to a focused, short-lived clipboard
  paste. The previous clipboard is restored and generated text is not retained there.
- Rich editors that advertise text or paste actions while reporting `isEditable=false`
  are recognized as input targets.
- A node action that fails or does not satisfy its post-condition escalates to visual
  grounding instead of repeating the same accessibility action.
- Visually grounded text entry is observed again after typing and must be present before
  the step is reported as successful.
- ChatGPT subscription sign-in now requires a renewable grant and a bounded lifetime,
  matching the current Codex/OpenClaw PKCE, refresh, and account-bound request contract.
- OAuth callback probes and stale redirects no longer consume the pending sign-in.

## Upgrade

The APK uses the same signing certificate as prior public releases and installs over an
existing Autobile installation without removing saved automations.

Android 11 or later is required.
