# Autobile 0.7.1

This patch closes a visual-routing gap exposed by canvas and game interfaces.

## Fixed

- A fresh screenshot is now explicitly recorded in execution history before visual
  grounding, making capture failures distinguishable from model-routing failures.
- A generic on-device policy restriction during image analysis can fall through to a
  cloud vision tier only when the user has already enabled cloud access and screenshot
  transfer. Text policy rejections and local-only skills remain terminal.
- Cloud screenshot consent is reported as policy, not as a missing model modality.
- ChatGPT subscription model discovery avoids catalog entries that explicitly reject
  image input.
- Onboarding no longer equates an accessibility connection with visual screen
  understanding.

## Privacy

Screenshots remain lazy and are captured only after deterministic and accessibility
matching cannot resolve the target. Cloud transfer still requires both cloud access and
the separate screenshot consent. Sensitive accessibility regions are masked before an
image leaves the device.

## Compatibility

- Android 11 or later
- Updates in place from prior signed releases
