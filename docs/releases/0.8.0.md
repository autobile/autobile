# Autobile 0.8.0

This release replaces phrase-matched game handling with an explicit visual-agent loop.

## Added

- A visual-task IR for games and canvas apps whose next action changes from frame to
  frame.
- Fresh screenshot observation before every action.
- Tap, long press, exact-point swipe/drag, wait, blocked, and completion decisions.
- Two-observation completion confirmation before a later Home or exit step can run.

## Changed

- Natural-language behavior edits are converted to a structured semantic plan by the
  selected reasoning runtime. The runtime returns an objective, visible completion
  criteria, and stable exit-step IDs; the app no longer recognizes a behavior request
  by listing Korean or English sentence fragments in code.
- ChatGPT Subscription light and advanced vision tiers choose distinct image-capable
  catalog fallbacks when the configured model is unavailable.

## Safety and limits

- Visual tasks are bounded, remain inside the learned package, and reject Android
  system-edge gestures.
- Secure windows, anti-cheat gesture blocking, purchases, ads, and unavailable image
  runtimes are not bypassed.
- This provides a general visual control primitive. It does not guarantee that a model
  can solve every game or long-horizon puzzle.

## Upgrade

Install over an existing version. Existing automations and ChatGPT Subscription sessions
are retained. Re-submit a previously saved phrase-matched behavior edit so it is compiled
to the new visual-task action.
