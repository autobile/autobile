# Autobile 0.6.2

This patch release fixes dynamic date and time values in text entered by an automation.

## Temporal input

- Detect a date or timestamp inside a multi-line note and preserve the surrounding text.
- Store the detected span as a relative runtime variable, so each run renders the actual
  date and time while retaining the format demonstrated by the user.
- Apply explicit current-date and current-time corrections to the compiled input step in
  both the post-teaching review and the saved automation editor.
- Give current-time corrections priority over schedule parsing when the request also
  contains an example clock value.

## Verification

The release workflow runs Android lint, all unit tests, debug assembly, minified release
assembly, APK signature verification, and SHA-256 generation from the protected `main`
commit before publishing artifacts.
